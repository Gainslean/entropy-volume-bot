# Entropy VOLUME — установка и запуск

Торговый бот для спреда между двумя биржами HIP-3 на Hyperliquid (рынки NBIS, DRAM, EWY, SNDK).
Режим **VOLUME** — на оборот: позиции закрываются логикой основного флота (не только в плюс, не дольше
15 минут). **Цель — около 30 $/100k после ожидаемого rebate; бот подстраивает входы к цели и не
останавливается из-за цены.** Это цель, а не гарантия каждой сделки: раз в час бот сверяет стоимость
последних суток по данным биржи и делает допуск новых входов строже или мягче.

Программа поставляется в скомпилированном виде (без исходного кода), настраивается сама и обновляется
кнопкой «Обновить» в панели. На одном сервере VOLUME может работать рядом с GREEN: у каждого своя папка,
свои службы, своя панель и свои кошельки (один счёт не может торговать в двух продуктах).

> Торговля связана с риском потерь. Бот ставит реальные ордера только после того, как вы явно
> включите торговлю. До этого он лишь проверяет настройки.

## 1. Что нужно

- Сервер **Linux**: Ubuntu 22.04 / 24.04 или Debian 12, 2 ядра, 2–4 ГБ памяти, 10 ГБ диска.
- Доступ к серверу по SSH с правами sudo.
- От 1 до 9 кошельков Hyperliquid с USDC — других, чем у GREEN на этом сервере.

## 2. Установка (одна команда)

Ссылку на архив и его sha256 присылает владелец. На сервере:
```bash
curl -fsSLO http://168.144.242.18:8080/get/entropy-volume-<версия>.tar.gz
echo "<sha256 из сообщения владельца>  entropy-volume-<версия>.tar.gz" | sha256sum -c || exit 1
tar xzf entropy-volume-<версия>.tar.gz
sudo bash entropy-volume-<версия>/install-volume.sh
```
Скрипт спросит только ключи кошельков (мастер или API; ввод скрыт, ключи хранятся только в
`/opt/entropy-volume/.env` с правами 600). Всё остальное он делает сам: проверяет архив, регистрирует ПК
у сервера настроек владельца, пишет профиль VOLUME, проверяет кошельки без ордеров, запускает панель по
ссылке и в конце предлагает включить торговлю.

## 3. Панель

`https://IP_СЕРВЕРА:8444`, логин `admin`, пароль — в конце установки. Показать снова:
```bash
sudo bash /opt/entropy-volume/install-volume.sh --show-login
```
В разделе «VOLUME» панели — допуск входа на цикл (B), оборот и стоимость за 24 часа, цель.

## 4. Команды

| Что | Команда |
|---|---|
| Состояние | `sudo bash /opt/entropy-volume/install-volume.sh --status` |
| Сменить кошельки | `sudo bash /opt/entropy-volume/install-volume.sh --set-wallets` |
| Включить торговлю | в панели или `sudo bash /opt/entropy-volume/install-volume.sh --live` |
| Обновить | кнопка «Обновить» или `sudo bash /opt/entropy-volume/install-volume.sh --update-now` |
| Журнал | `sudo journalctl -u entropy-volume -f` |
| Удалить | `sudo bash /opt/entropy-volume/install-volume.sh --uninstall` |

Службы: `entropy-volume` (бот), `entropy-volume-dashboard` (панель, 127.0.0.1:8766),
`entropy-volume-gateway` (панель по ссылке, порт 8444). Канал обновлений:
`http://168.144.242.18:8080/volume`.

Раз в минуту бот отправляет на мониторинг владельца счётчики без адресов кошельков и ключей (версия, оборот, стоимость, число сделок и сбоев); сервер видит IP установки.
